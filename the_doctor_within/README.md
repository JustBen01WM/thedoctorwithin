# The Doctor Within — starter build

A responsive browser-game home screen and arcade-world map for **The Doctor Within**.

## Run it
1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Click the buildings, daily challenge, profile, and About button to explore the current shell.

## What's included
- 3D-inspired cartoon arcade home screen.
- Mediverse map with six interactive destinations.
- XP, coins, level progress and badge counter.
- Daily challenge card and modal interactions.
- Responsive desktop and mobile layout.
- Dr. Hope character introduction using the approved natural-afro design (no jewellery).

## Important
This is the **world and home-screen foundation**, not the finished game. Heartbeat Hero is now playable from the Physiology Lab or the daily challenge card. It includes Easy, Normal and Expert rhythm modes, combo scoring, accuracy feedback, XP and coin rewards. Coins, XP and badge progress are saved in the browser. Other destinations are still previews while their activities are developed.

Dr. Hope now appears in the home screen using an original 3D-inspired character illustration. Her approved design has a natural afro, purple headband, purple scrubs, white coat and stethoscope, with no jewellery.
